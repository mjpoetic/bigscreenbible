# Google Play developer profile artwork

These files are for the account's **Play developer profile**, separate from the app listing's icon, screenshots and feature graphic.

- `developer-icon-512.png`: existing Big Screen Bible artwork; 512 × 512, opaque PNG, approximately 214 KB.
- `developer-header-4096x2304.jpg`: matching dark-and-gold header; 4096 × 2304, opaque JPEG. See file size verification before upload.

Upload through **Developer account → Play developer profile → Developer page**. Use the icon under Developer icon and the header under Header image. Each file must be under 1 MB. Preview Google's displayed crop before saving.

The header is generated artwork based on the existing app branding. Its text is “BIG SCREEN BIBLE” and “Read. Study. Share.”
