# Celebration music

`joyful-complete.mp3` uses the public-domain Ode to Joy melody (Ludwig van Beethoven), also used for “Joyful, Joyful, We Adore Thee.”

`heaven-complete.mp3` uses the refrain of HEAVEN, Emily D. Wilson (1898), from “When We All Get to Heaven.” Public-domain status and notation: https://library.timelesstruths.org/music/When_We_All_Get_to_Heaven/ and https://hymnary.org/tune/heaven_wilson (checked September 7, 2026).

Both are original synthesized retro arrangements generated by `scripts/generate-game-music-auditions.mjs`, without recordings or samples from another performer. Run `npm run audio:game-music` to regenerate all tracks, or `node scripts/generate-game-music-auditions.mjs --production --heaven-only` for the new refrain.

The cues alternate during perfect-result/record celebrations. Their playback gains are matched to approximately -34.5 dB mean volume at the full game-volume setting; the game-volume slider scales both.

## Game soundtrack loops

All nine game soundtracks (including timed Reference Rush) use lossless, stereo 16-bit WAV files at 44.1 kHz. This gives the decoder an exact sample count with no MP3 priming or end padding. The app repeats a decoded buffer on the audio clock; it can use that path even if native media-element routing fails.

The arrangements keep their melody and percussion present from the first bar, without intro-only gaps or abrupt switches in instrumentation. Notes and delay tails wrap around the musical boundary. Before export, the final four bars blend into the first four bars using matching chords and downbeats. A 5 ms runtime smoothing window removes sample discontinuities at the join.

Run `npm run audio:game-music` to reproduce the WAV loops and MP3 result cues. Existing MP3 game tracks are retained as legacy assets; they are no longer selected for gameplay. The WAV assets total about 33 MiB. Only the selected soundtrack is fetched and decoded.

When changing a composition's tempo or bar count, update its `loopSeconds`: `(source beats - 16) * 60 / bpm`. Music URLs include an asset revision. Music, word-selection feedback, and countdowns share one audio context, with independent gains. Pauses preserve the position; new rounds reset it. Result cues play once.
