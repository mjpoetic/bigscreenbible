## Android signing handoff

Dane is unsure whether an upload key exists. A filename search in this repository, Downloads, and `~/.android` found only the debug keystore. This is a limited search, not proof that no upload key exists elsewhere. If an existing key is found in a password manager or another backup, reuse it rather than replacing it.

If this is the app's first Play release and no upload key exists:

1. Open this project's `android` directory in Android Studio.
2. Choose **Build → Generate Signed App Bundle or APK → Android App Bundle**.
3. Choose **Create new** for the keystore. Save the `.jks` in a private location, choose a key alias (for example `bigscreenbible-upload`), use at least 25 years of validity, and enter strong passwords yourself. Use the same password for the keystore and key, as Android Studio recommends. Do not paste passwords into chat.
4. Back up the keystore and save the keystore password, alias, and key password in your password manager before publishing. Make a recovery copy outside this checkout.
5. Select **release** and generate the signed AAB. Share its file path so its signature, certificate fingerprint, version, and alignment can be verified.

Play App Signing and the upload key are distinct. After Play enrollment, update `assetlinks.json` with the Play **app-signing certificate** fingerprint. The existing fingerprint must not be assumed to match that certificate. No upload or agreement acceptance is authorized by this handoff.
