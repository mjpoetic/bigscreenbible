# Widget fonts

These font files are included directly in ScriptureWidget.appex and listed in UIAppFonts. Regular weight is used for Scripture; UI labels keep system typography. No runtime font download is needed.

- Literata and Inter: copied unchanged from assets/fonts, with existing OFL licenses.
- Lora: unmodified upright variable TTF from https://github.com/google/fonts/tree/main/ofl/lora (default weight 400).
- Source Sans 3: unmodified regular static TTF from https://github.com/adobe-fonts/source-sans/tree/release/TTF.
- Lora and Source Sans 3 downloaded 2026-10-31; their OFL licenses are included.

Test installed widgets on a physical iPhone before beta acceptance; standalone/native build success does not prove WidgetKit host rendering.
